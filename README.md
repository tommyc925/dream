# dream.sociallux.io

The Dreamer's Ticket, unfolded — a letter, one file, no build step.

This page is the permanent substrate behind the printed tickets. Printed ink is
law: the URL on the cards never changes, and this page never shares fate with
the platform's deploys (ratified 2026-10-02). Design record lives on The
Dreamer's Ticket canvas.

## Deploy (GitHub Pages)

1. Create a **public** repo, push this tree to its default branch.
2. Repo Settings → Pages → Deploy from branch → `main` / root. The `CNAME`
   file in the tree sets the custom domain.
3. DNS: add a `CNAME` record `dream` → `<github-username>.github.io`.
   Enable "Enforce HTTPS" once the cert issues.
4. Platform side (separate): `sociallux.io/dream` redirects here;
   create the `dream@sociallux.io` mailbox **before** any card prints.
